Traffic-Mirroring Validation Platform

A complete shadow-traffic subsystem that duplicates live production search traffic to the new Trino backend — Lambda mirror, CloudFormation-deployed pipeline with DLQs, request replayer, and automated result/latency comparison — so the migration was proven against real production workload before any customer was switched.

Sigma → SQL Query Compilation

Profile

Full-stack
of the data platform

XDL — the XDR Search Data Lake — stores consolidated security logs from Trend Micro products worldwide and serves the search, aggregation, and detection workloads behind Trend Vision One. Queries arrive in a Sigma-based language and are compiled into KQL, Trino SQL, or OpenSearch DSL depending on the backend.

I'm one of the few engineers who has worked every layer of this platform: the search APIs and their query compilers, the streaming ingestion pipelines, the distributed query engines underneath, the Terraform/Ansible infrastructure across every production region, and the monitoring that keeps it honest at 3 a.m.

My defining project: leading the migration of the entire platform off Azure Data Explorer onto an Apache Iceberg + Trino lakehouse — from the first engine survey and gap analysis, through building the new ingestion and query layers, to a traffic-mirrored, staged production cutover.

Foundation & Scale-Out

2022 — 2024

Search Evolution & Pipeline 3.0

Owned search API features — V3 auto-sliding pagination, Sigma operators, async job APIs — plus reporting, threat-sweeping KQL optimization, observability and auto-remediation. Drove the 2023 pipeline reconstruction with PoCs and benchmarking.

Sovereign Cloud & Due Diligence

Enabled sovereign/private-cloud deployments on OpenSearch through a pluggable search-engine refactor. Ran the build-vs-buy evaluations — GCP BigQuery PoCs, Spanner limits, engine surveys, Iceberg ingestion survey — that set the next-generation architecture direction.

The Lakehouse Migration

Technical lead of the ADX → Iceberg/Trino migration: gap analyses and risk evaluation, new ingestion pipeline, Trino search layer, traffic-mirroring validation, performance and cost engineering, and staged production cutover with EMR-based historical backfill.
